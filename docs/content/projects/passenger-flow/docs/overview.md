# Passenger Flow Forecasting

This independent MATLAB code case demonstrates a complete static publishing pipeline.

- `generate_data.m` creates deterministic passenger-flow data and a transparent baseline forecast.
- `generate_plots.m` builds four result figures.
- `main.m` publishes JSON, PNG, and source-code copies for the repository website.

## Run in MATLAB

```matlab
addpath('matlab');
main
```

> The website only displays published files. It never executes MATLAB in the browser.
