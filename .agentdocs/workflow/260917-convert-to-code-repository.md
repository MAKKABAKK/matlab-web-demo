## 覆盖声明

本需求完全取代此前“教学用具、单项目教程、课程/课时”产品定义。后续设计、文案和实现不得再把网站理解为单一项目教学课件。

## 产品目标

将现有静态内容渲染框架改造为 MATLAB 机器学习代码案例仓库：

1. 一级导航是模型分类。
2. 二级导航是互相独立的 MATLAB 代码案例。
3. 选中案例后，右侧显示该案例自己的章节、说明、代码、结果数据与图表。
4. 网页只做静态浏览，不运行 MATLAB。
5. 新增分类、案例和章节时只修改 catalog/manifest 与内容文件，不修改 HTML。

## 架构边界

- catalog 负责模型分类树与案例索引。
- manifest 负责单个案例的章节和资源。
- 当前案例章节大纲独立显示，不作为分类树的第三级目录。
- 保留英文/繁体中文切换、hash 深链接、静态部署与共享 MATLAB 发布流程。
- 保留现有视觉设计令牌，只调整信息架构所需组件。
- 支持本地 Markdown 文档、PNG、JSON 与 MATLAB 源码；禁止远端脚本与在线执行。
